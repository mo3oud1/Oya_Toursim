## تفعيل النشر على GitHub Pages (مرة واحدة)

1. Settings ← Pages
2. Source: **Deploy from a branch** ← Branch: **main** ← Folder: **/ (root)** ← Save
3. بعد دقيقة يصبح الموقع على: `https://oyatourism.com/` (الدومين المربوط عبر ملف `CNAME`؛ العنوان الاحتياطي: `https://mo3oud1.github.io/Oya_Toursim/`)

> ملاحظة: GitHub Pages المجاني يتطلب أن يكون المستودع **Public**.
> عند ربط دومين خاص (مثل oyatourism.com) غيّر `url` في `_src/site.mjs` ثم أعد البناء، وأضف ملف `CNAME`.

## تعديل المحتوى

كل النصوص في ملفات البيانات داخل `_src/content/`، والإعدادات العامة في `_src/site.mjs`:

- `site.mjs` — الهاتف، البريد، ساعات العمل، **رقم رخصة TÜRSAB**، العنوان، روابط التواصل الاجتماعي، Google Analytics، Search Console.
- `destinations.mjs` — وجهات تركيا.
- `packages-turkey.mjs` / `packages-world.mjs` — البرامج (ضع `priceFrom` لإظهار السعر «يبدأ من»).
- `visas-saudi.mjs` / `visas-gcc-intl.mjs` — صفحات التأشيرات.
- `posts.mjs` — مقالات المدونة.
- `hotels.mjs` — صفحات فنادق المدن.
- `services-extra.mjs` — الخدمات السريعة والعروض الموسمية.
- `_src/pages/matches.mjs` — جدول المباريات (عدّل المواعيد والملاعب فور الإعلان الرسمي).

ثم شغّل:

```bash
node _src/build.mjs
```

يولّد الصفحات، `sitemap.xml`، `robots.txt`، ويفحص الروابط المكسورة، ويحدّث `IMAGES.md`.

## اللغات (العربية + English · Русский · Türkçe · Português)

- العربية هي الأصل وتبقى على جذر الموقع. النسخ الأخرى على `/en/` و`/ru/` و`/tr/` و`/pt/` وتُبنى تلقائياً من الصفحات العربية.
- الترجمات في `_src/i18n/<lang>.json` (كل جملة عربية لها معرّف قصير)، والمحرّك في `_src/lib/i18n.mjs`.
- إذا عدّلت نصاً عربياً أو أضفت صفحة، يطبع البناء عدد الجمل الناقصة لكل لغة (`missing`)، وقائمتها في `_src/i18n/_missing.json`، والنص العربي لكل معرّف في `_src/i18n/source.json`. تُترجم الجمل الناقصة وتُضاف إلى ملف اللغة ثم يُعاد البناء — ولا تُنشر لغة فيها جمل ناقصة.
- عناصر تحمل `translate="no"` (أسماء اللغات في القائمة مثلاً) لا تُترجم.

## لوحة تحكم الأسعار (قاعدة البيانات)

- الأسعار كلها في ملف واحد: `data/prices.json` (أسعار تذاكر كأس السوبر حسب الفئة A+ / A / B / C، وسعر «يبدأ من» لكل برنامج، والعملة).
- تعديلها من اللوحة: **https://oyatourism.com/admin/** — الدخول بمفتاح GitHub (Fine-grained token) على هذا المستودع فقط، بصلاحية Contents: Read and write. خطوات إنشائه مكتوبة داخل اللوحة.
- كل حفظ يُسجَّل كتعديل في GitHub (يمكن الرجوع إليه)، وتظهر الأسعار الجديدة على الموقع خلال دقائق دون إعادة بناء، لأن الصفحات تقرأ الملف عند فتحها. وعند إعادة البناء تُكتب الأسعار داخل الصفحات نفسها أيضاً.
- الخانة الفارغة = «عند الطلب» (المباريات) أو «حسب الموسم» (البرامج).

## التقنيات

- HTML/CSS/JS بدون أطر عمل — مولّد ثابت بسيط (`_src/build.mjs`، Node بدون حزم).
- الخطوط: **Alexandria** (العناوين) و **Readex Pro** (النصوص) — مستضافة محلياً (SIL OFL).
- الأيقونات: **Lucide** (ISC) + أيقونات سياحية مخصصة.
- الحركة: **GSAP** (Flip / ScrollTrigger) تُحمَّل فقط في الصفحات التي تخدم فيها الحركة قرار المستخدم (تصفية البرامج، خط سير البرنامج).
- الكرة الأرضية التفاعلية: **COBE** (MIT) — تُحمَّل عند الوصول إليها فقط وتتوقف خارج الشاشة.
- SEO: عناوين ووصف فريد لكل صفحة، Canonical، Open Graph، JSON-LD (TravelAgency، TouristTrip، TouristDestination، Service، FAQPage، BlogPosting، SportsEvent، BreadcrumbList)، خريطة موقع.
- تجربة المستخدم: مبادئ Baymard للنماذج والحجز (حقول مطلوبة/اختيارية واضحة، أخطاء عربية بجانب الحقل، رسائل طمأنة، حفظ المسودة، زر حجز ثابت على الجوال).
